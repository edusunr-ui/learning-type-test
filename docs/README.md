# 학습유형검사 웹사이트

GitHub Pages에 그대로 올릴 수 있는 정적 웹사이트입니다.

## 배포

1. 이 `docs` 폴더를 GitHub 저장소에 포함합니다.
2. GitHub 저장소의 `Settings > Pages`에서 `Deploy from a branch`를 선택합니다.
3. Branch는 `main`, 폴더는 `/docs`로 지정합니다.

## 동작 방식

- 초등부는 42문항, 중등부/고등부는 60문항입니다.
- 기존 프로그램에서 확인한 6개 척도 구조와 유형 매핑을 사용합니다.
- 학생 답변은 서버로 전송하지 않고 브라우저 `localStorage`에 임시 저장됩니다.
- 결과 화면은 브라우저 인쇄 기능으로 PDF 저장 또는 출력할 수 있습니다.
