# 학습유형검사 웹사이트

완성된 GitHub Pages용 사이트는 `docs` 폴더에 있습니다.

## 빠른 확인

`docs/index.html`을 브라우저에서 열면 바로 사용할 수 있습니다.

## GitHub Pages 배포

1. 이 폴더를 GitHub 저장소로 업로드합니다.
2. GitHub 저장소에서 `Settings > Pages`로 이동합니다.
3. `Deploy from a branch`를 선택합니다.
4. Branch는 `main`, Folder는 `/docs`로 지정합니다.

## 포함된 기능

- 초등부, 중등부, 고등부 검사 선택
- 원본 검사지 PDF 보기
- 문항 번호별 1~5점 체크
- 미응답 문항 이동
- 브라우저 임시 저장
- 기존 프로그램 기준 유형 산출
- 유형별 결과 PDF 보기
- 결과 화면 인쇄/PDF 저장
